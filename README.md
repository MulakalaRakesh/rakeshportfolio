# The Silent Downgrade — motion graphics short

A Remotion (React-based) motion graphics piece that renders to MP4.

## Preview in a live studio
```
npm install
npm start
```
Opens Remotion Studio at http://localhost:3000 — scrub the timeline, preview each scene, edit React components and see changes live.

## Render to MP4
```
npm install
npm run build
```
Output: `out/silent-downgrade.mp4` (1920×1080, 30 fps, ~50 seconds).

## Scenes
1. Cold open — "6,852 sessions. 200,000 actions. 73% dumber."
2. GitHub issue scroll — Stella Lorenzo's post
3. Bar chart drop — 6.6 → 2.0 code reads
4. Split-screen comparison — Feb vs Mar output
5. Silent workflow node shift
6. Raghava close — three-beat reframe

Edit `src/SilentDowngrade.tsx` to tune timing, copy, or visuals.
